# logic
This repository contains a proof-search algorithm based on the formalization of Corsi and Tassi's terminating Gentzen's multi-succedent sequent calculus named IG. The logic was extended to capture unprovability by refutation calculus called RIG. Soundness and completeness of the algorithm have been formally proven.

## Documentation

The generated documentation is available here:  
https://lnooj.github.io/ig/
